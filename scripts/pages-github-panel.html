GitHub 私有备份

将记录备份到你自己的私有仓库。每次创建独立快照，历史备份会保留；恢复前可确认内容。

首次使用：在 GitHub 创建细粒度令牌 ↗，仅选择 daily-done-backups 仓库，仓库权限 Contents 设为 Read and write，并设置有效期。

令牌只在当前页面内存中使用，仅发送至 GitHub。刷新后需重新填写；不要把令牌发到聊天中。

启用时立即备份，成功后才开启自动备份。之后有未备份修改时，最多等待 10 分钟就自动备份，持续编辑不会推迟；失败会稍后重试。同一浏览器的多个标签页会协调并跳过重复内容。页面需保持打开；关闭页面或电脑休眠会阻止或延迟备份。刷新后重新启用会先备份当前全部记录。
