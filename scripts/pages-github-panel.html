手机与电脑同步

在手机和电脑分别连接同一个 GitHub 私有仓库。首次连接会自动合并本机记录与最新旧版备份，并保留迁移副本；原有历史备份不会删除。

首次使用：在 GitHub 创建细粒度令牌 ↗，仅选择 daily-done-backups 仓库，仓库权限 Contents 设为 Read and write，并设置有效期。

默认仅本次页面使用；勾选后令牌会保存在本浏览器，请只在个人设备使用。“清除授权”可移除。令牌仅发送给 GitHub，不会写入备份，也不要发到聊天中。

保存后约 2 秒上传；页面打开时约每 30 秒读取另一端更新，切回页面和恢复联网时立即检查。关闭页面、后台限速或休眠会延迟同步。离线修改保留在本机，下次连接继续合并。同一条记录同时修改时按修订顺序确定显示版本，所有旧版本仍可下载找回。
